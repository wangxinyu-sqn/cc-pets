# Security Policy

English | [简体中文](./SECURITY.zh-CN.md)

## Supported versions

Security fixes are prioritized for the latest release and the `main` branch.

## Reporting a vulnerability

Do not disclose an unpatched vulnerability, credentials, or private session data in
a public Issue. Use GitHub's **Security → Report a vulnerability** private reporting
form and include:

- the affected CC Pets version and macOS version;
- reproduction steps and the impact;
- only the minimum necessary logs, with tokens, cookies, usernames, and local paths removed.

After the maintainer confirms the issue and prepares a fix, coordinate the timing
of public disclosure.
